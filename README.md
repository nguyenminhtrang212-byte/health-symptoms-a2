# Tự học A2 – Health: Illnesses & Symptoms

Trang tự học một file (`index.html`), không cần cài đặt.

1. Thẻ học ngẫu nhiên (từ / cụm / câu dài) + 20 câu hỏi
2. Sắp xếp từ thành câu (5 câu) + chép lại câu (5 câu)
3. Brainstorm: đau họng, sốt, đau răng thì nên làm gì
4. Viết thư cho bạn, đọc lại và ghi âm, nộp bài

Bật GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
